# 選用工具逐步教學

[文件首頁](README.md) · [第一次操作主流程](usage.md) · [English](../en/tools.md)

這些工具依需求使用，不必全部跑過。先從下表選目的，再看對應章節；
所有「來源」都指伺服器檔案，除非檢視器明確提供本機開檔。

| 想完成的事 | 使用工具 | 安排在什麼時候 |
| :--- | :--- | :--- |
| 素材在雲端／成果要傳回雲端 | [資料：GCS 下載／上傳](#gcs) | 重建前搬入、完成後搬出 |
| 確認照片有沒有清楚、抽幀有沒有成功 | [圖片](#images) | 任何照片處理前後 |
| 把照片背景遮掉 | [影像去背](#matte) | 需要前景遮罩的 COLMAP／訓練之前 |
| 同一物件正擺、倒擺兩輪合成一個模型 | [融合](#fusion) | 兩輪都去背完成之後、COLMAP 之前 |
| 訓練需要深度或法線監督 | [深度／法線](#depth) | 正確訓練影像確定後、啟動訓練前 |
| 大場景想分成較小場景訓練 | [分塊](#blocks) | COLMAP 去畸變完成後 |
| 想知道網格高寬深或兩點距離 | [量測](#measure) | 有可用 Mesh 之後 |

例子中的 `/Disk0/my-scan` 與 `gs://my-bucket` 都是占位範例，請換成你有權限的實際路徑。
若功能灰色，先請管理者依「環境檢查」補齊該工具，而不是改填不相干的後端。

<a id="gcs"></a>

## 1. GCS：把素材下載到伺服器，把成果傳回雲端

**進入：**「＋ 建立任務」→「切換功能」→「資料」。此頁同時有下載和上傳兩張表單。
需要伺服器已安裝並完成 gsutil 的雲端存取設定；網頁登入帳密不等於 GCS 權限。

### 下載範例

| 欄位 | 例子 | 核對方式 |
| :--- | :--- | :--- |
| 來源（GCS） | `gs://my-bucket/my-scan/images` | 是實際 bucket 路徑，不是 Google Cloud 網頁網址 |
| 下載到（本機） | `/Disk0/my-scan/images` | 這裡的本機是伺服器；上層目錄可寫入 |

1. 直接貼來源，或用「☁️ 瀏覽」選雲端位置。
2. 第一次建議明確填目的地，較容易知道素材到哪裡；留空時依畫面的自動目的地規則處理。
3. 按「下載」，在「目前工作」看搬移日誌；不要一邊下載一邊對半套素材跑重建。
4. 等「已完成」，記下「已下載到」路徑。
5. 用「圖片」檢查照片，或切換抽幀／COLMAP，把這個**伺服器路徑**選為來源。

**常見卡點：**列不出 bucket 可能是專案／授權設定；權限拒絕需管理者確認 GCS 權限。
下載到瀏覽根目錄以外時，後續選擇器可能看不到，需貼完整路徑。
重跑同步通常只補差異，但仍要看日誌與完成狀態，不能用舊的完成任務推斷本次已更新。

### 上傳成果範例

1. 先確認模型或網格任務已完成，來源包含你想保存的實際成果。
2. 在「上傳到 GCS」填來源，例如 `/Disk0/my-scan/model-run-01`。
   多選時按「瀏覽」，勾選檔案／資料夾後按「套用所選」；進入資料夾與勾選它是不同操作。
3. 填「目的地(GCS)」，例如 `gs://my-bucket/results/my-scan/run-01`。
   新實驗用獨立目的地，避免混淆同名版本。
4. 按「上傳到 GCS」，等待完成，再用雲端瀏覽或管理工具核對實際目的地、檔名與數量。
5. 確認雲端成果可讀取後才自行決定本機保留策略；上傳任務不代表所有相依檔案已自動挑齊。

單一資料夾走同步，單檔／多選走複製；目的地結構以搬移日誌及實際雲端結果為準。
照片貼圖 OBJ 要連同 MTL 與圖片，依賴原照片的資料集／符號連結也不能只看目錄名字就當完整備份。

<a id="images"></a>

## 2. 圖片：先確認素材和處理結果

1. 切換功能 →「圖片」，填「伺服器上的圖片資料夾」。
2. 需要包含抽幀的各子資料夾就勾「含子資料夾」；只看指定層時取消。
3. 按「開啟圖片牆」，點縮圖放大，用畫面箭頭或鍵盤左右鍵看前後張，Esc 關閉放大。
4. 檢查是否正確專案、方向正常、有足夠清晰細節，相鄰照片是否真有共同內容。
5. 抽幀或縮圖後再看一次實際輸出，不只看原始素材。

**看不到照片：**先看填入的是不是工作區根目錄而非照片目錄、有沒有子資料夾、格式是否可讀。
HEIC 來源可能需額外解碼依賴／轉換，若出錯將檔案格式與訊息交給管理者。
照片去背的透明邊緣請用「檢視去背結果」的專用檢視，避免一般縮圖背景造成誤判。

<a id="matte"></a>

## 3. 影像去背：先把照片中的前景選對

**適用：**只想重建一件物體，或物體在不同拍攝輪次中翻面、背景不能參與重建。
它改的是照片遮罩；訓練後在 SuperSplat 刪點雲是[另一個流程](usage.md#viewers)。

### 欄位怎麼選

| 欄位 | 如何填／選 |
| :--- | :--- |
| images | 實際照片資料夾，或含 `images/` 的 COLMAP 工作區 |
| 提示方式 | 相機移動且照片有順序：匡選＋追蹤；位置固定：固定框；文字／範例則需相容模型 |
| 模型 | 追蹤用 SAM 2；想用 SAM 3 範例／文字功能選對應提示方式，依畫面相容性限制 |
| 解析度 | 選定長邊後，各輪保持一致；接 COLMAP 時選相同影像版本 |
| 輸出 | 後續要 COLMAP／融合就必須有 `masks/`；第一輪保留 cutout＋masks 可同時檢視 |
| GPU | 已可用、分配給你的顯卡 |
| 邊緣處理／進階 | 先保留預設，看到具體邊界問題再調整 |

### 第一次用框選＋追蹤

1. 填 `images`，選 SAM 2 與「匡選＋追蹤傳播」；素材必須是有順序的拍攝序列。
2. 按「匡選物體」，右邊會出現照片。拖曳框住要保留的完整主體，不是背景。
3. 點一下是增加前景提示，Shift＋點是背景提示；點已有標記可刪除它，錯了用「復原」。
4. 用「上一張／下一張」檢查視角變化，必要時在其他影格補錨點。
   一張種子會影響整個序列，不是只處理框過的照片；但也不保證一個框適合所有變化。
5. 核對輸出包含 masks，再按「開始去背」。沒框、模式不相容或環境未就緒時先按提示修正。
6. 執行中看結果預覽；完成後按「檢視去背結果」，切透明格／白／黑／綠背景，空白鍵對照原圖。
7. 特別看物體邊緣、細小突出處、透明或反光部位。有壞圖就由結果檢視進入單張修正，
   不要把明顯錯誤的遮罩直接交給整批重建。

### 成果放哪、怎麼接下一步

- `no_bg/cutout/`：RGBA 圖，給人看透明背景或其他支援工具。
- `no_bg/masks/`：單通道遮罩，給 COLMAP／訓練使用；不要拿 RGBA 圖代替它。
- 有先縮圖時，輸出跟著 `images_<長邊>/` 那份照片，並放在其中的 `no_bg/`。
  以本次任務顯示的路徑為準，不再去原圖資料夾找。

接 COLMAP 時，照片來源選與遮罩對應的那份影像，`MASKS_DIR` 填 `no_bg/masks`。
要讓背景不參與相機解算，開「遮罩也用在抽特徵」；要讓**去畸變輸出的照片**背景塗黑，
另選「輸出的照片也去背」。後者會修改輸出資料集影像，不是只改預覽，也不是刪除原始拍攝檔。
已有一致縮圖時可用「保持原樣」避免再縮成不同尺寸。

**檢查點：**照片與遮罩相對檔名／尺寸需對得上。固定框用在主體四處移動的序列會錯位；
追蹤種子選錯可能整段都錯。新設定的比較結果應另存，覆蓋選項只在確定要重做時使用。

## 4. 融合：同一物件的正擺、倒擺兩輪一起重建

融合不是把兩個任意 3D 模型合併，而是整理**兩輪照片與遮罩**供共同 COLMAP 解算。

1. 兩輪各自完成影像去背，選相同解析度，確認各自都有可用的 `no_bg/masks/`。
2. 切「融合」，第 1 組填例如 `/Disk0/my-scan/up/images_2560/no_bg`，
   第 2 組填 `/Disk0/my-scan/down/images_2560/no_bg`。
3. 「融合輸出資料夾」可填 `/Disk0/my-scan/fusion-run-01`；留空會依兩組共同上層推算。
4. 按「整理並檢查」，查看每組照片／遮罩數量與尺寸；有缺漏先回去修。
5. 按結果中的「帶入 COLMAP 表單」，檢查已帶入照片、遮罩、工作目錄及相關選項。
   這類分次拍攝不要開同步多相機 rig，保留一致尺寸；確認後再按「啟動 COLMAP」。
6. 完成後看兩輪是否都有相機／影像註冊，而不是只重建其中一輪。
   結果正常才從此工作目錄接訓練。

輸出包含 `images/<每組>`、`masks/<每組>` 與 `colmap/`。
前兩者使用符號連結指回來源，不是複製一份照片，因此不要在下游使用前移走／刪除原始去背資料。
若兩輪仍分離，先檢查遮罩和輪次間的共同視角；資料本身缺乏銜接時需補素材，
不是「整理並檢查」成功就代表融合品質一定成功。

## 5. 深度／法線：為訓練準備額外的影像資訊

**前提：**所選訓練後端確實使用深度／法線，且對應工具已可用。第一輪基本訓練可先不啟用。

1. 先決定訓練實際使用哪份照片。若使用 COLMAP 去畸變資料集，就用其中的 `images/`，
   不用最初未去畸變、另一解析度的照片。
2. 切「深度／法線」，選可用引擎；LichtFeld 的 MoGe-2 與獨立 MoGe-3 由不同環境執行。
3. `images` 填該資料集／照片資料夾，「產生內容」選需要的深度、法線或兩者，再選 GPU。
4. 第一輪保留模型與位元深度預設，按「產生深度／法向量圖」。第一次可能需下載模型，
   請看日誌，不重複提交。
5. 完成後確認與 `images/` 同層有 `depth/`、`normals/` 中所選的資料，檔名與照片對應。
6. 回到訓練表單，用同一份 source，展開後端的深度／法向量監督區，
   勾所需「深度損失」／「法向量損失」，確認權重後才啟動訓練。

**常見誤解：**只產生圖，不代表訓練一定會讀它；只勾損失，也不能假定此引擎已產生對應圖。
來源解析度／照片改了要重新確認對齊。預設略過已存在成果，改設定後若要重算，
明確決定新輸出或「覆蓋已存在的深度／法向量圖」。不要把舊圖混當新設定的成果。

<a id="blocks"></a>

## 6. 分塊：把已重建的大場景切成可獨立訓練的小場景

1. 先完成 COLMAP 與去畸變，確認整體模型可用，再切「分塊」。
2. `source` 填該 workspace／去畸變輸出；`out_dir` 第一次可明確填
   `/Disk0/my-scan/blocks-run-01`，留空時畫面說明會建立 `source/blocks/<時間>`。
3. 第一次可勾「自動分塊」，讓相機分布決定塊大小與 buffer；先保留進階門檻。
   「影像切片」會產生裁切池，未開則連結來源影像，依你的訓練需求選擇。
4. 全場景處理時 `region` 留空。只要特定區域，可由 COLMAP 檢視器「選訓練範圍」帶入，
   確認範圍座標屬於這份模型，不貼另一個模型的 minx/miny。
5. 按「開始分塊」，等完成後選一塊「檢視這塊」，檢查相機和覆蓋範圍。
6. 按「帶入訓練」，核對 source 是指定 `block_<ix>_<iy>`，每塊使用獨立模型輸出再提交。
   建立分塊不會自動把全部子塊訓練完成或合併成最終模型。

成果有每塊的 `images/`、`sparse/` 及總 `manifest.json`，切片時另有 `_tiles/`。
不要移除這些相依資料，也要保留連結指向的來源。block_size／buffer 使用模型座標單位；
只有確認已對齊為公尺時才按公尺理解。只需裁一塊且不分格時，使用「只裁切不分塊」。

## 7. 量測：分清楚兩點距離、外形尺寸與實際毫米

### 在 Viewer 裡量兩點

開 Mesh Viewer → 勾「量尺」→ 依序點模型表面兩點 → 讀距離 → 按「清除」重新量。
量尺只量你選的兩點；右側單位按鈕只是標籤，不會做真實尺寸校正。

### 產生高／寬／深與三視圖

1. 從完成的 Mesh 任務按「量測高寬深」，或切換功能 →「量測」，選伺服器 Mesh 路徑後按「開始量測」。
2. 確認頁面有正面、側面、俯視三張圖與高寬深表。
3. 若方向不對，先看「PCA 主軸」／「原始 XYZ」：PCA 自動找延伸方向，XYZ 使用原座標。
4. 調整「哪一軸是高度」、寬深互換／翻轉，直到三視圖符合你要定義的方向；
   物體歪斜時直接抄高寬深容易量到不想要的方向。
5. 沒有校正比例時保留 units。知道比例才填「實際尺寸換算」的 `mm_per_unit`，按「套用」。

**倍率例子：**已確認模型中的 2 units 對應實物 100 mm，倍率是 `100 / 2 = 50` mm/unit，
應填 `50`，不是填 `100`、`mm` 或只改 Viewer 單位標籤。
若檔案座標本來已是 mm，才填 `1`。這個範例只說明換算；比例依可靠的已知尺寸或標定結果建立，
不會自動保證量測精度，也不會把任意模型改造成標定過的實物。

此頁做的是量測顯示換算；要另外產生已縮放的 mesh，需使用 Mesh 的標定／縮放成果流程。
有背景碎片時，外形範圍可能被拉大，先清理或確認測量的是正確模型。

<a id="handoff"></a>

## 8. 下一步到底要填哪個路徑

| 已完成的工具 | 下一步來源 | 不要誤填成 |
| :--- | :--- | :--- |
| GCS 下載 | 任務顯示的伺服器下載目的地 | 原 `gs://` 路徑直接丟給 COLMAP |
| 抽幀 | 帶入的照片輸出根目錄 | 原始影片檔 |
| 影像去背 | 同尺寸照片＋`no_bg/masks/` | RGBA cutout 充當單通道遮罩 |
| 融合 | 整理後共同 `images/`、`masks/`，由表單帶入 | 其中任意一輪舊工作目錄 |
| COLMAP | 含去畸變資料的 workspace／資料集 | 只有 sparse PLY 或原始照片夾 |
| 深度／法線 | 與產生圖對應的同一訓練資料集 | 不同解析度的另一包照片 |
| 分塊 | 選定的 `block_<ix>_<iy>` | 包含所有塊的父目錄直接當單一場景 |
| 訓練 | 完成任務的模型資料夾／檢視按鈕 | 另一個後端、不相容的模型輸出 |

每次送出前重新看來源、輸出與所選功能，完成後核對任務顯示的路徑。
需要基本流程、狀態判讀或排錯時，返回[啟動後完整教學](usage.md)。
